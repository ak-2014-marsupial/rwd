# Англійська як конструктор: Посібник зі збірки речень

Більшість людей вчать англійську, намагаючись склеювати окремі слова. Але носії мови використовують готові блоки — **Chunks**. Це як деталі Lego: у кожного блоку є свій «роз'єм» (Interface), який визначає, що саме можна приєднати далі.

---

### 1. Логіка конвеєра та Таблиця сумісності

Речення збирається строго **зліва направо**. Ви не можете перестрибнути через етап, бо кожен попередній Chunk готує місце для наступного. Використовуйте цю таблицю як шпаргалку для перевірки «роз'ємів»:

| Код модуля | Що вимагає справа (T-PoS) | Технічна роль |
| :--- | :--- | :--- |
| **IC[Verb]** | **+ Verb (Infinitive)** | Задає намір та час. «Двигун» речення. |
| **AC[Noun]** | **+ Noun або Пусто** | Виконує дію. Містить вбудовані прийменники. |
| **QC[Noun]** | **+ Noun** | Уточнює кількість або частку (фільтр). |
| **OC** | **Кінець або CC** | Називає конкретний об'єкт. |
| **CC[Noun]** | **+ Noun / Clause** | Додає обставини (де, коли, чому). |

---

### 2. Керування "Двигуном": Особи та Час

**IC[Verb]** — це єдина точка контролю граматики. Якщо ви змінюєте виконавця (Subject), змінюється лише форма **IC**, а весь інший ланцюжок залишається незмінним.

*   `I want to` + `check` + `the bugs`.
*   `She wants to` + `check` + `the bugs`. (Змінився лише IC)
*   `We're going to` + `check` + `the bugs`. (Змінився лише IC)

Це дозволяє вам міняти «голову» речення, не переробляючи все інше.

---

### 3. Бібліотека блоків (Приклади)

*   **IC[Verb] (Intent):** `I want to`, `I'm going to`, `Do you want to?`, `I used to`, `She needs to`.
*   **AC[Noun] (Action):** `have a look at`, `talk about the`, `check`, `go back to`, `fix the`.
*   **QC[Noun] (Quantity):** `some of the`, `one of the`, `a lot of`, `most of the`, `part of the`.
*   **OC (Object):** `errors`, `plans`, `new rules`, `data`, `tasks`.
*   **CC[Noun] (Connector):** `because of the delay`, `at the end of the day`, `before the meeting`.

---

### 4. Приклади збирання речень (Assembly Examples)

Використовуючи чанки з бібліотеки вище, ми можемо створювати сотні комбінацій. Ось як виглядає шлях збірки:

*   **IC → AC:**
    `She needs to` + `fix the` + `data`.
    *(Їй потрібно виправити дані).*
*   **IC → AC → QC → OC:**
    `I used to` + `go back to` + `some of the` + `new rules`.
    *(Раніше я повертався до деяких нових правил).*
*   **IC → Word → CC:**
    `I'd like to` + `rest` + `at the end of the day`.
    *(Я б хотів відпочити наприкінці дня).*
*   **IC → AC → QC → OC → CC:**
    `Do you want to` + `talk about the` + `one of the` + `plans` + `before the meeting`?
    *(Ти хочеш обговорити один із планів перед зустріччю?)*
*   **CC → IC → AC → OC:**
    `Because of the delay`, `I'm going to` + `check` + `the tasks`.
    *(Через затримку я збираюся перевірити завдання).*

---

### 5. Гібридне стикування та Особливості CC

#### **Гібридний режим**
Ви можете вставити власне слово, якщо воно відповідає типу роз'єму:
*   **IC[Verb] + Дієслово:** `I want to` + **rest**.
*   **AC[Noun] + Іменник:** `check` + **bugs**.

#### **Гнучкість CC (Виняток конвеєра)**
**CC[Noun]** — це єдина деталь, яка може «перестрибнути» в самий початок речення для створення акценту:
*   `I'm going to check the bugs` + `at the end of the day`.
*   `At the end of the day`, `I'm going to check the bugs`.

---

### 5. Приклади збірки: Рівні складності

**Мінімальна збірка (MVP):**
*   `I want to` + `rest`. (IC[Verb] + Word)
*   `She needs to` + `check`. (IC[Verb] + AC[Noun])

**Складна збірка (Об'єкт з фільтром):**
*   `Do you want to` (**IC**) + `have a look at` (**AC**) + `some of the` (**QC**) + `errors` (**OC**)?
    *(Бажаєш поглянути на деякі з помилок?)*

**Максимальна збірка (Повний ланцюг):**
*   `I'd like to` (**IC**) + `talk about the` (**AC**) + `one of the` (**QC**) + `plans` (**OC**) + `before the meeting` (**CC**).
    *(Я б хотів обговорити один із планів перед зустріччю).*

### Рекомендації для Anki (Метадані)

Для максимальної ефективності використовуйте теги та окремі колоди для кожного типу Chunk:

1.  **Лицьова сторона:** `Код модуля` + `Англійська фраза` — Переклад.
    *   *Приклад:* `AC[Noun] talk about the` — поговорити про.
2.  **Зворотна сторона:** 2-3 приклади використання.
3.  **Тегування:** Додавайте теги `#IC`, `#AC`, `#QC`, `#CC`.
    *   *Порада:* Тренуйте колоду `IC` окремо, щоб довести до автоматизму перемикання між "Я хочу", "Вона хоче", "Ми збираємося". Це дозволить вам миттєво обирати правильний «двигун» для будь-якої дії.
