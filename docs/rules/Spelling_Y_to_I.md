# Зміна Y на I (Changing Y to I)

Це правило визначає, чи змінюється літера **y** при додаванні закінчень `-ed`, `-es` або `-er`.
This rule determines whether the letter **y** changes when adding suffixes like `-ed`, `-es`, or `-er`.

### Головна перевірка (The Main Check):
Подивіться на літру **перед** **y**.
Look at the letter **before** **y**.

### Логіка (The Logic):
* **Приголосна + Y (Consonant + Y)** → **Змінюємо** **y** на **i**.
    * *Examples:* `study + ed` → **studied**, `fly + es` → **flies**, `happy + er` → **happier**.
* **Голосна + Y (Vowel + Y)** → **Нічого не змінюємо**.
    * *Examples:* `play + ed` → **played**, `stay + es` → **stays**, `boy + s` → **boys**.

### Важливе зауваження (Important Note):
Це правило зазвичай **не діє** при додаванні закінчення **-ing**, щоб уникнути подвійної "ii".
This rule usually **does not apply** when adding **-ing** to avoid "ii".
* *Example:* `study + ing` → **studying**.
