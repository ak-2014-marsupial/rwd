# Огляд вебдодатка «Parrot» — вашого персонального помічника у вивченні мов

Parrot (англ. Папуга) — це інструмент, що базується на самій суті вивчення мови: багаторазовому слуханні та точному відтворенні. Назва додатка відображає його головну методику — допомогти користувачеві «перейняти» вимову та лексику через імітацію та циклічне повторення.

### 1. Доступність

Додаток є браузерним рішенням, доступ до якого здійснюється за посиланням: **[https://ak-2014-marsupial.github.io/rwd/](https://ak-2014-marsupial.github.io/rwd/)**.

Завдяки підтримці технології **Progressive Web App (PWA)**, його можна зберегти на головний екран смартфона або робочий стіл комп'ютера у вигляді іконки. Це забезпечує миттєвий запуск без необхідності відвідування магазинів додатків.

### 2. Безпека та конфіденційність

Використання додатка є цілком безпечним завдяки архітектурі сучасних браузерів:

* **Технологічна ізоляція (Sandboxing):** Додаток працює в захищеному середовищі («пісочниці»), не маючи доступу до вашої операційної системи чи особистих файлів.
* **Відсутність інсталяції:** Програма не вносить змін у системний реєстр, що повністю виключає ризик втручання в роботу пристрою.
* **Захищений протокол:** Робота через **HTTPS** гарантує шифрування даних.

### 3. Синтез мовлення та Web Speech API

В основі функціонала лежить використання **Web Speech API** — безкоштовної технології перетворення тексту в голос (**Text-to-Speech**).

> **Зауваження щодо сумісності:** Якість та природність звуку залежать від рушія синтезу в браузері. На сьогодні найкраща реалізація представлена в **Google Chrome**, який рекомендовано як основний для цього додатка.

### 4. Валідація середовища (Тестова сторінка)

При першому запуску автоматично відкривається діагностична сторінка, яка дозволяє:

* Миттєво перевірити роботу синтезатора мовлення на різних мовах.
* Отримати інформацію про тип та версію вашого браузера для підтвердження сумісності.

### 5. Поточний функціонал

Наразі в додатку реалізовано сценарій тренування, який надає повний контроль над процесом навчання:

* **Керування кількістю повторів:** можливість встановити необхідну кількість відтворень для кожного запису.
* **Налаштування пауз:** регулювання тривалості пауз між повторами для комфортного промовляння слів за диктором.


### 6. Робота з даними

* Зовнішні дані надходять у простому текстовому форматі, який легко переглядати та редагувати.
* При першому відкритті дані автоматично завантажуються в пам'ять додатка. Система самостійно відстежує оновлення та попереджає користувача про появу нових або змінених записів.


### 7. Перспективи розвитку: Створення власного контенту

У подальшому планується надати користувачам можливість самостійно формувати навчальні набори, що дозволить вийти за межі централізованих оновлень:

* **Авторське наповнення:** у планах є впровадження функціонала для створення індивідуальних списків слів, що забезпечить максимальну персоналізацію навчання.
* **Імпорт через «Copy-Paste»:** завантаження персональних даних буде реалізовано через просте копіювання тексту. Користувачі зможуть використовувати вже розроблений **спеціалізований текстовий формат**, який ідеально розпізнається додатком.
* **ШІ-підтримка:** для підготовки даних у цьому форматі вже створено відповідний **промпт для ШІ**. Достатньо надати нейромережі звичайні речення англійською мовою, і вона миттєво згенерує готовий до вставки блок тексту.
* **Локальна конфіденційність:** весь самостійно доданий контент зберігатиметься **виключно на локальному пристрої** користувача, що гарантує повну приватність.

### 8. Технічні вимоги

* **Браузер:** Google Chrome (версія 90+), Microsoft Edge або Safari.
* **Інтернет-з'єднання:** необхідне для завантаження додатка та голосових пакетів.
* **Звук:** справні динаміки або навушники; вимкнений "режим тиші" на пристрої.
* **Підтримка PWA:** використання функції «Додати на початковий екран» (Safari) або «Встановити додаток» (Chrome).
