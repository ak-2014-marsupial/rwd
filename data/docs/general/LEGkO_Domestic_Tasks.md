### 🏗️ Lego Construction Site: Domestic Tasks

**Available Modules:**
*   **IC:** `[Entry] I need to [Verb]`, `[Entry] It takes time to [Verb]`, `[Entry] There is a lot of work in [Noun]`, `[Subj] needs [Noun]`.
*   **AC:** `[Verb] mow the grass in [Noun]`, `[Verb] clean the area near [Noun]`, `[Verb] fix the fence along [Noun]`, `[Verb] water the plants in [Noun]`.
*   **QC:** `[Noun] a piece of [Noun]`, `[Noun] a couple of [Noun]`, `[Noun] plenty of [Noun]`.
*   **CC:** `[Noun/Adj] instead of [Noun]`, `[Noun/Adj] due to [Noun]`, `[Noun/Adj] along with [Noun]`.
*   **Verb:** `paint`, `repair`, `sweep`, `check`, `remove`, `plant`.
*   **Adj:** `dirty`, `broken`, `tidy`, `overgrown`, `wet`.
*   **Noun:** `the garden`, `the backyard`, `the roof`, `the lawn`, `the neighbors`, `tools`, `trash`.
*   **Subj:** `The house`, `The generator`, `The gate`, `The garden`.
*   **Entry:** `[Empty]`, `And`, `But`, `Actually`, `Usually`, `Today`, `Now`, `First of all`.

### ⚙️ Assembly Line: Domestic Tasks

#### **1. Formula: IC + Word(Verb/Noun)**
*   `I need to(IC)` + `paint(Verb)` + `the fence(Noun)`
    👉 **I need to paint the fence.** — Мені потрібно пофарбувати паркан.
*   `Usually(Entry)` + `the generator(Subj)` + `needs(IC)` + `repair(Noun)`
    👉 **Usually the generator needs repair.** — Зазвичай генератор потребує ремонту.

#### **2. Formula: IC + Adj**
*   `Now(Entry)` + `the lawn(Subj)` + `is(IC)` + `tidy(Adj)`
    👉 **Now the lawn is tidy.** — Тепер газон охайний.
*   `The roof(Subj)` + `is(IC)` + `wet(Adj)`
    👉 **The roof is wet.** — Дах мокрий.

#### **3. Formula: IC + AC + Noun**
*   `Actually(Entry)` + `I need to(IC)` + `water the plants in(AC)` + `the garden(Noun)`
    👉 **Actually I need to water the plants in the garden.** — Взагалі-то, мені потрібно полити рослини в саду.
*   `First of all(Entry)` + `it takes time to(IC)` + `fix the fence along(AC)` + `the backyard(Noun)`
    👉 **First of all it takes time to fix the fence along the backyard.** — Перш за все, потрібен час, щоб полагодити паркан уздовж заднього двору.

#### **4. Formula: IC + QC + Noun**
*   `There is a lot of work in(IC)` + `plenty of(QC)` + `trash(Noun)`
    👉 **There is a lot of work in plenty of trash.** — Тут багато роботи з великою кількістю сміття.
*   `I need to(IC)` + `check(Verb)` + `a couple of(QC)` + `tools(Noun)`
    👉 **I need to check a couple of tools.** — Мені потрібно перевірити пару інструментів.

#### **5. Formula: IC + Adj + CC + Noun**
*   `The backyard(Subj)` + `is(IC)` + `dirty(Adj)` + `due to(CC)` + `the storm(Noun)`
    👉 **The backyard is dirty due to the storm.** — Задній двір брудний через шторм.
*   `Usually(Entry)` + `the grass(Subj)` + `is(IC)` + `wet(Adj)` + `along with(CC)` + `the lawn(Noun)`
    👉 **Usually the grass is wet along with the lawn.** — Зазвичай трава мокра разом із газоном.

#### **6. Formula: IC + AC + QC + CC + Noun**
*   `Today(Entry)` + `I need to(IC)` + `remove(Verb)` + `a huge amount of(QC)` + `overgrown(Adj)` + `grass(Noun)` + `instead of(CC)` + `the weekend(Noun)`
    👉 **Today I need to remove a huge amount of overgrown grass instead of the weekend.** — Сьогодні мені потрібно видалити величезну кількість зарослої трави замість вихідних.
*   `But(Entry)` + `it takes time to(IC)` + `clean the area near(AC)` + `a couple of(QC)` + `neighbors(Noun)` + `regardless of(CC)` + `the tools(Noun)`
    👉 **But it takes time to clean the area near a couple of neighbors regardless of the tools.** — Але потрібен час, щоб прибрати територію біля кількох сусідів, незалежно від інструментів.
